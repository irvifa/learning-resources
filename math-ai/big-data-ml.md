## MIT

### Mathematics of Big Data and Machine Learning (RES.LL-005)
- **Platform:** MIT OpenCourseWare
- **Level:** Undergraduate
- **Term:** January IAP 2020
- **Link:** https://ocw.mit.edu/courses/res-ll-005-mathematics-of-big-data-and-machine-learning-january-iap-2020/
- **Instructors:** Dr. Jeremy Kepner, Dr. Vijay Gadepally
- **Description:** Introduces the Dynamic Distributed Dimensional Data Model (D4M), which merges graph theory, linear algebra, and databases to tackle big data challenges. Covers signal processing approaches to ML, with applications in search algorithms, social media analysis, fraud detection, and bioinformatics. Materials include lecture videos, notes, and homework assignments.
