# C and C++ Programming

Courses covering C programming, memory management, object-oriented C++, and systems-level development.

> **Access notes**
> - MIT OCW: entirely free, no registration required

---

## MIT

### Practical Programming in C (6.087)
- **Platform:** MIT OpenCourseWare
- **Level:** Undergraduate
- **Term:** January IAP 2010
- **Link:** https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/
- **Instructors:** Daniel Weller, Sharat Chikkerur
- **Description:** Thorough introduction to C with a focus on its role in UNIX systems and embedded development. Covers fundamentals, dynamic memory allocation, concurrency and synchronization, UNIX signals and process control, and library development. Includes daily programming assignments and weekly lab exercises.

### Introduction to C Memory Management and C++ Object-Oriented Programming (6.088)
- **Platform:** MIT OpenCourseWare
- **Level:** Undergraduate
- **Term:** January IAP 2010
- **Link:** https://ocw.mit.edu/courses/6-088-introduction-to-c-memory-management-and-c-object-oriented-programming-january-iap-2010/
- **Instructors:** Eunsuk Kang, Jean Yang
- **Description:** Progresses from basic C programs through manual memory management to C++ classes and the Standard Template Library. Emphasizes why you would choose C/C++ for performance-critical and memory-sensitive work, with applications to systems programming and technical interviews.

### Effective Programming in C and C++ (6.S096)
- **Platform:** MIT OpenCourseWare
- **Level:** Undergraduate
- **Term:** January IAP 2014
- **Link:** https://ocw.mit.edu/courses/6-s096-effective-programming-in-c-and-c-january-iap-2014/
- **Instructor:** Andre Kessler
- **Description:** Fast-paced introduction to C and C++ emphasizing good programming practices and effectiveness. Covers OOP, memory management, optimization, and the comparative advantages of C/C++. Recommended for students with prior programming experience. Includes weekly assignments and a final project.

### Introduction to C++ (6.096)
- **Platform:** MIT OpenCourseWare
- **Level:** Undergraduate
- **Term:** January IAP 2011
- **Link:** https://ocw.mit.edu/courses/6-096-introduction-to-c-january-iap-2011/
- **Instructors:** Jesse Dunietz, Geza Kovacs, John Marrero
- **Description:** Fast-paced introductory course covering C++ fundamentals and C++-specific constructs and concepts. Designed for those with little prior programming background.
