## MIT

### Distributed Algorithms (6.852J)
- **Platform:** MIT OpenCourseWare
- **Level:** Graduate
- **Term:** Fall 2009
- **Link:** https://ocw.mit.edu/courses/6-852j-distributed-algorithms-fall-2009/
- **Instructor:** Prof. Nancy Lynch
- **Description:** Foundational treatment of algorithms designed to run on multiple processors without tight centralized control. Covers impossibility results, self-stabilization, wait-free computability, failure detectors, and scalable concurrent programming for shared-memory systems. Materials include lecture notes and problem sets.
