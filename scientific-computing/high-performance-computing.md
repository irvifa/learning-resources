# High Performance Computing

Free courses on parallel computing, HPC tools, GPU programming, and distributed systems from notable universities.

> **Access notes**
> - MIT OCW: entirely free, no registration required
> - Udacity / Coursera: free to audit
> - Georgia Tech course pages: public lecture materials and videos

---

## MIT

### Parallel Programming for Multicore Machines Using OpenMP and MPI (12.950)
- **Platform:** MIT OpenCourseWare
- **Level:** Graduate
- **Term:** January IAP 2010
- **Link:** https://ocw.mit.edu/courses/12-950-parallel-programming-for-multicore-machines-using-openmp-and-mpi-january-iap-2010/
- **Instructor:** Dr. Constantinos Evangelinos
- **Department:** Earth, Atmospheric, and Planetary Sciences
- **Description:** Hands-on introduction to shared and distributed memory programming using OpenMP and MPI. Covers fundamentals of mixed parallel programming geared toward numerical applications. Includes lecture notes and problem sets.

### Performance Engineering of Software Systems (6.172)
- **Platform:** MIT OpenCourseWare
- **Level:** Undergraduate
- **Term:** Fall 2018
- **Link:** https://ocw.mit.edu/courses/6-172-performance-engineering-of-software-systems-fall-2018/
- **Instructors:** Prof. Charles Leiserson, Prof. Julian Shun
- **Description:** Hands-on, project-based introduction to building scalable and high-performance software systems in C. Covers performance analysis, instruction-level and caching optimizations, parallel programming, algorithmic techniques for high performance, and building scalable systems. An 18-unit course with strong project emphasis.

### Multicore Programming Primer (6.189)
- **Platform:** MIT OpenCourseWare
- **Level:** Undergraduate
- **Term:** January IAP 2007
- **Link:** https://ocw.mit.edu/courses/6-189-multicore-programming-primer-january-iap-2007/
- **Instructors:** Dr. Rodric Rabbah, Prof. Saman Amarasinghe
- **Description:** Introductory parallel programming course covering multicore architecture design philosophies and parallel programming best practices. Students gain hands-on experience via group projects on multicore platforms. Supported by Sony, IBM, and Toshiba.

### Parallel Computing (18.337J)
- **Platform:** MIT OpenCourseWare
- **Level:** Graduate
- **Link:** https://ocw.mit.edu/courses/18-337j-parallel-computing-fall-2011/
- **Description:** Advanced interdisciplinary introduction to applied parallel computing on modern supercomputers. Uses Julia. Covers the realities and myths of what is possible on the world's fastest machines, with hands-on emphasis.

## UIUC

### Heterogeneous Parallel Programming
- **Platform:** Coursera (free to audit)
- **Level:** Intermediate
- **Link:** https://www.classcentral.com/course/hetero-427
- **Description:** GPU and heterogeneous computing with CUDA C, OpenCL, OpenACC, and C++AMP. Covers data parallel execution models, memory locality, tiling techniques, and parallel algorithm patterns.

## Georgia Tech

### High Performance Computing
- **Platform:** Udacity (free)
- **Level:** Graduate
- **Link:** https://www.classcentral.com/course/udacity-high-performance-computing-1028
- **Instructor:** Rich Vuduc
- **Description:** Fundamentals of HPC — parallel algorithms, efficiency analysis, and implementation with MPI, OpenMP, and CUDA. Requires C/C++ background.

### CSE 6230: HPC Tools and Applications
- **Platform:** Georgia Tech (public course page)
- **Level:** Graduate
- **Link:** https://vuduc.org/cse6230/
- **Instructor:** Rich Vuduc
- **Description:** Hands-on HPC tools and applications course. Lecture videos and materials from Spring 2024 are publicly available.

### CSE 6220: Intro to High-Performance Computing
- **Platform:** Georgia Tech OMSCS (public syllabus)
- **Level:** Graduate
- **Link:** https://omscs.gatech.edu/cse-6220-intro-high-performance-computing
- **Description:** Algorithm design for parallel and memory-efficient computation. Syllabus and some materials are publicly accessible.
