## MIT

### Computational Methods of Scientific Programming (12.010)
- **Platform:** MIT OpenCourseWare
- **Level:** Undergraduate
- **Term:** Fall 2024
- **Link:** https://ocw.mit.edu/courses/12-010-computational-methods-of-scientific-programming-fall-2024/
- **Instructors:** Prof. Thomas Herring, Dr. Chris Hill
- **Department:** Earth, Atmospheric, and Planetary Sciences
- **Description:** Modern programming approaches used by physical scientists. Emphasizes code design, algorithm development and verification, and the comparative advantages of Python, Julia, and C/C++. Topics include numerical analysis, visualization, machine learning, cloud computing, HPC workflows, version control, reproducible research practices, and code-sharing standards. Materials include lecture notes, problem sets, and Jupyter notebooks.
